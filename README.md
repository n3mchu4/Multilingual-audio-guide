# Multilingual Automatic Audio/Video Narration System

An application that automatically generates multilingual narration for audio/video content. The system transcribes speech from the source file, translates it into a target language, and synthesizes a new narration track, with synchronized bilingual subtitles.

## Tech Stack

- **Web:** React.js (Vite)
- **Mobile:** React Native (Expo)
- **Backend:** Firebase / Supabase (minimal backend layer for auth, storage, and orchestration)
- **AI Services:** OpenAI Whisper (Speech-to-Text), Google Translate / DeepL (Translation), Google Cloud TTS / Azure Speech (Text-to-Speech)
- **CI:** GitHub Actions (lint, type-check, build verification)

## Folder Overview

| Folder | Purpose |
|---|---|
| multilingual-audio-guide/ | Main application workspace containing the frontend, backend functions, shared code, docs, and CI config |
| web/ | React + Vite frontend for the web app |
| mobile/ | Mobile app project area |
| shared/ | Shared API, type definitions, constants, and utility logic reused across projects |
| functions/ | Backend/serverless logic and local API mock/dev server |
| docs/ | Product requirements, design docs, API contracts, and demo scripts |
| .github/workflows/ | GitHub Actions for CI checks |
| node_modules/ | Installed dependencies generated by npm; not source code |
